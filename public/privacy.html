개인정보처리방침

여행 가계부 (travel-ledger) · 시행일 2026-11-06

1. 수집하는 정보

구글 로그인 시 Google이 제공하는 계정 식별자, 이메일 주소, 이름, 프로필 사진 URL만 저장합니다. 비밀번호는 수집하지 않습니다.

서비스 이용 중 사용자가 직접 입력한 여행 정보와 지출 내역(금액, 통화, 카테고리, 메모, 장소, 일시)을 저장합니다.

2. 이용 목적

로그인 상태 유지와 사용자별 데이터 분리, 그리고 사용자가 입력한 가계부를 보여주고 통계를 계산하는 용도로만 사용합니다. 광고나 제3자 마케팅에 사용하지 않습니다.

3. 보관 및 삭제

데이터는 사용자가 삭제하거나 탈퇴를 요청할 때까지 보관됩니다. 앱의 설정 화면에서 여행과 지출을 직접 삭제할 수 있고, 계정 전체 삭제는 아래 연락처로 요청하면 처리합니다.

4. 제3자 제공

데이터를 제3자에게 판매하거나 제공하지 않습니다. 호스팅(Vercel)과 데이터베이스(Turso) 사업자가 서비스 운영을 위해 데이터를 저장·처리합니다. 환율 조회 시 외부 환율 API에 통화 코드만 전송되며 개인정보는 전송되지 않습니다.

5. 캡처 가져오기 (선택 기능)

결제 내역 스크린샷을 올려 지출을 자동 입력하는 기능을 사용하면, 이미지는 내역 추출을 위해 Google Gemini API로 전송되어 처리됩니다. 이미지는 서버나 데이터베이스에 저장되지 않으며 추출된 텍스트(가맹점·금액·일시)만 사용자가 저장을 선택한 경우에 가계부에 기록됩니다. 이 기능은 운영자가 허용한 계정에서만 활성화됩니다.

6. 쿠키 및 로컬 저장소

로그인 토큰과 최근 조회한 환율을 브라우저 로컬 저장소에 보관합니다. 추적 쿠키나 분석 도구는 사용하지 않습니다.
